# Dataset Info

**Source Link:** [UCI Machine Learning Repository - Beijing Multi-Site Air-Quality Data Set](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data)
**Size:** 420,768 hourly observations across 12 monitoring stations (2013–2017) with 18 features.

**How to obtain the data:**
The raw data is already downloaded and included in this repository (under 50 MB compressed). If you need to re-download it, you can run the `src/download_data.py` script.
